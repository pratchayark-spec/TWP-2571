# ระบบติดตามโครงการน้ำ จังหวัดจันทบุรี 2569





- C: อปท.
- E: ชื่อโครงการ
- H: ตำบล
- I: อำเภอ
- J: จังหวัด
- K: ลุ่มน้ำ
- L: ลุ่มน้ำสาขา
- Q: งบประมาณตามข้อมูลต้นทาง
- EO: สถานะโครงการ
- EP–ES: สถานะเอกสาร 4 ประเภท

## กติกาตรวจเอกสาร
ค่ามากกว่า 0 = มีเอกสาร
ค่าว่าง หรือ 0 = ขาดเอกสาร

EP = ข้อเสนอโครงการ / ศึกษาความเหมาะสม
EQ = ที่ดิน
ER = แบบรูปรายการ
ES = ประมาณราคา

## ฟังก์ชันในเว็บ
- Dashboard ภาพรวม KPI และกราฟ
- แผนที่รายอำเภอ (คลิกเพื่อกรองโครงการ)
- รายโครงการ + ค้นหา + ตัวกรอง
- ตรวจเอกสารและแสดงรายการที่ขาด
- ราย อปท. พร้อมอัตราความพร้อม
- จัดอันดับ อปท. และอันดับความเสี่ยง
- เปิดรายละเอียดโครงการในหน้าต่างสรุป
- ส่งออกข้อมูล CSV

## นำขึ้น GitHub Pages
1. สร้าง Repository ใหม่ เช่น `lpa-chanthaburi-2569`
2. อัปโหลด `index.html` และ `data.js`
3. Settings > Pages > Deploy from branch > เลือก branch `main` และโฟลเดอร์ `/ (root)`
4. เปิด URL ที่ GitHub Pages สร้างให้
