# TWP 71 – ระบบติดตามโครงการน้ำ จังหวัดจันทบุรี 2569

เวอร์ชันปรับปรุงการจัด Layout ทั้ง Desktop และ Mobile โดยคงการเชื่อม Google Sheets / Apps Script เดิมไว้

ไฟล์หลัก:
- `index.html` หน้าเว็บ
- `Code.gs` Google Apps Script สำหรับดึงข้อมูล
- `data.js` ข้อมูลสำรองกรณีเชื่อมต่อสดไม่ได้

การติดตั้ง: ใช้ `index.html` แทนไฟล์เดิมใน GitHub Pages โดยไม่ต้องเปลี่ยนลิงก์เว็บไซต์ และคง `Code.gs` ตัวเดิมที่เชื่อม Google Sheets ได้ไว้
